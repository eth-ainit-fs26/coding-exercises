Confidence Intervals

Understand how confident you should be in your estimates — and watch intervals shrink as you gather more data.

What is a Confidence Interval?

A single number like 0.6 tells us our estimate, but how certain is it? A confidence interval gives us a range that's likely to contain the true value. Wider interval = less certain. Narrower = more data, more confident.

📐 The Formula
Confidence Interval
( p̂ₙ − 1/√n , p̂ₙ + 1/√n )

Where p̂ is our estimated probability and n is the sample size. Larger n → smaller margin → tighter interval.

Exercise · Implement the CI

urn_helpers.py · compute_confidence_interval()
Using the formula above, compute the margin and set the lower and upper bounds. Remember: √n = n0.5 in Python.
def compute_confidence_interval(sample):
if len(sample) == 0:
return (0.0, 1.0)
p_hat = frequentist_estimation(sample)
n = len(sample)
margin =
lower = max(0.0, p_hat - margin)
upper = min(1.0, p_hat + margin)
return (lower, upper)

In Python, n ** 0.5 is √n. So 1.0 / n ** 0.5 gives 1/√n. This is your margin.

The Estimate-then-Exploit Game

You're a digital marketer. One of two ads secretly performs much better. With a budget of 200 shows — how much do you spend estimating?

Ad A has a 30% click rate. Ad B has a 70% click rate (much better!). But you don't know which is which until you measure. Every show spends 1 unit of budget.

The Strategy

The "Estimate-then-Exploit" strategy has two phases:

Phase 1 · Estimate

Show each ad n times. Record clicks. This costs 2n budget. You get an estimate of each ad's click rate.

Phase 2 · Exploit

Show the seemingly better ad for the remaining 200 − 2n shows. Maximise total clicks!

Game 4

Proto-UCB Algorithm

Upper Confidence Bounds — a smarter strategy that automatically balances exploration and exploitation, with zero hyperparameters.

The Idea: Optimistic Selection

Instead of randomly exploring (like Thompson Sampling), Proto-UCB is optimistic: it always picks the urn that could potentially be best. For each urn it computes an upper confidence bound and selects the highest.

1️⃣
Estimate
Compute p̂ from samples
2️⃣
Upper Bound
UCB = p̂ + 1/√n
3️⃣
Select Best
Pick highest UCB

Early on: few samples → wide intervals → optimism pushes you to explore. Later: many samples → narrow intervals → you focus on the truly best urn. No ε to tune!

Understanding Proto-UCB

Key insight: Empty urns get UCB = 1.0 (maximum possible), so the algorithm must explore them first. As you gather data, the intervals shrink and the truly best urn emerges.

Vs. Epsilon-Greedy: UCB adapts automatically — explores more early, exploits more later. No ε to tune, and typically lower regret especially when ε is poorly chosen.
